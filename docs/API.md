# Контракты REST API

Версия магазина: 1.0.0. Базовый URL при локальном запуске: `http://127.0.0.1:8000/api/v1/`.
Обмен — UTF-8 JSON; для файлов изображений административный CRUD также принимает multipart/form-data. Списки возвращаются массивами без пагинации в учебной версии.

## Авторизация

Публичны чтение каталога и фракций, получение OpenAPI и вход. Корзина, заказы и ИИ-подбор требуют токен:

```http
Authorization: Token <токен_пользователя>
```

Токен возвращает `POST auth/login/`. Веб-клиент хранит его в sessionStorage вкладки; GUI — в памяти процесса. `POST auth/logout/` отзывает токен пользователя, включая доступ с другого клиента под тем же токеном. Для демонстрации входа используйте `demo / WarhammerDemo2026!`. Административные изменения каталога разрешены только `is_staff`.

## Сущности

### Faction

`id`: integer, `name`: string, `description`: string, `logo`: URL изображения или null. Имя уникально, не более 100 символов.

### Product

| Поле | Тип | Назначение |
|---|---|---|
| id | integer | Идентификатор |
| name | string | Уникальное название, до 200 символов |
| faction | Faction или null | Вложенная фракция; только чтение |
| faction_id | integer или null | Фракция при записи; только запись |
| product_type | enum | MINIATURE, STARTER_SET, PAINT, ACCESSORY, BOOK |
| category_label | string | Русское название категории; только чтение |
| description | string | Описание |
| price | decimal string | Базовая цена, больше нуля, 2 знака после точки |
| discounted_price | decimal string | Актуальная цена со скидкой; только чтение |
| stock | integer | Неотрицательный остаток |
| image | URL или null | Фотография |
| tags | string | Ключевые слова, до 300 символов |
| beginner_friendly | boolean | Подходит ли новичку |
| image_source | URL string | Страница-источник изображения |

ProductWrite использует перечисленные изменяемые поля. Для создания обязательны name, product_type, description, price; stock по умолчанию 0, beginner_friendly — false. Стартовые наборы получают скидку 10%; сервер округляет цену до копеек через Decimal.

### Фильтрация products/

- `search` — подстрока названия, описания или тегов (до 200 символов). Для русского текста в SQLite учитывайте ограничения встроенного case-insensitive поиска; используйте написание из карточек.
- `faction` — положительный идентификатор фракции. Общие товары без фракции при этом исключаются.
- `type` — код категории из Product.product_type.
- `min_price`, `max_price` — границы актуальной цены со скидкой, от 0 до 1 000 000.
- `in_stock=true` или `1` — исключить нулевые остатки.
- `ordering` — id (по умолчанию), price, -price, name.

Пример: `GET products/?type=STARTER_SET&max_price=6000&in_stock=true&ordering=price`.

### Cart, CartItem, Order

Cart: `id`, `items` (массив CartItem), `total_price` (строка Decimal), `total_quantity` (integer).
CartItem: `id`, `product` (Product), `quantity`, `total_price`.
Количество при добавлении/изменении — целое от 1 до 999 и не больше текущего остатка. Для удаления используется DELETE, нулевое количество не принимается.

Order: `id`, `total_price`, `created_at` (ISO 8601 с часовым поясом), `status` (PROCESSING), `items`.
Позиция заказа: `product` (ID или null после удаления товара), `product_name`, `unit_price`, `quantity`, `total_price`.
Название и цена копируются в заказ и не меняются после редактирования/удаления товара. Остатки уменьшаются и корзина очищается в одной транзакции; при недостатке любого товара вся операция отменяется. Платежи и доставка в учебной версии не интегрированы.

## Запрос и ответ ИИ-подбора

```http
POST /api/v1/recommendations/
Content-Type: application/json
Authorization: Token <токен_пользователя>
```

```json
{
  "preferences": "Я новичок. Хочу начать собирать космодесант и попробовать покраску.",
  "budget": "6000.00",
  "max_items": 3
}
```

| Поле | Обязательное | Ограничения |
|---|---|---|
| preferences | Да | От 5 до 1200 символов после обрезки краевых пробелов |
| budget | Да | Decimal, от 1 до 1 000 000, до 2 дробных знаков |
| max_items | Нет | От 1 до 5 разных товаров, по умолчанию 3 |
| faction | Нет | Положительный ID; null означает отсутствие ограничения |
| product_type | Нет | Код категории |

Ответ 200:

```json
{
  "items": [
    {
      "product": {"id": 2, "name": "Гвардия Ворона", "discounted_price": "2250.00", "stock": 6},
      "quantity": 1,
      "reason": "Набор подходит для первого знакомства с космодесантом.",
      "total_price": "2250.00"
    }
  ],
  "total_price": "2250.00",
  "budget": "6000.00",
  "explanation": "Подбор проверен по текущим ценам и наличию. Все выбранные товары вместе укладываются в бюджет.",
  "model": "@cf/meta/llama-3.3-70b-instruct-fp8-fast",
  "cached": false
}
```

В примере product сокращён; в реальном ответе возвращается полный Product. Текст reason генерируется моделью и может различаться. Пустой items — нормальный результат, если нет кандидатов или корректного набора. При отсутствии кандидатов модель не вызывается, model=`none`. Рекомендация не является резервированием.

Одинаковый запрос с тем же набором и характеристиками кандидатов кешируется на 300 секунд в памяти процесса Django. На вход и ИИ-подбор действует ограничение 10 запросов в минуту (для входа — IP, для подбора — пользователь). В многопроцессной учебной конфигурации кеш и счётчики отдельны для каждого процесса.

## Ошибки магазина

| HTTP | Значение |
|---|---|
| 400 | Некорректные поля/фильтры, пустая корзина, превышен остаток |
| 401 | Нет действующего токена или неверные данные входа |
| 403 | Недостаточно прав для административной записи |
| 404 | Объект не существует либо принадлежит другому пользователю |
| 405 | Метод не поддерживается |
| 429 | Ограничение частоты; повторить позже |
| 503 | Worker не настроен, недоступен, вернул ошибку или некорректный JSON |

Ошибки полей имеют формат `{"quantity":["…"]}`; общие ошибки — `{"detail":"…"}`. Клиенты показывают содержимое этих сообщений. Сведения о ключах и исходное тело ошибки провайдера клиентам не передаются.

## Отдельный облачный сервис

Адрес: `https://warhammer-ai-recommendations.canadyleon58.workers.dev`.

`GET /health` публичен и возвращает `service`, `status`, `version`, `model`. Наличие health-ответа проверяет доступность Worker; реальный вызов ИИ отдельно подтверждён `live_validation.json`.

`POST /recommendations` принимает JSON и служебный ключ:

```http
Authorization: Bearer <RECOMMENDATIONS_API_KEY>
Content-Type: application/json
```

Это отдельный случайный ключ Worker, а не Cloudflare API Token и не токен пользователя Django.

```json
{
  "preferences": "Нужна синяя краска для первой миниатюры",
  "budget": "1000.00",
  "max_items": 2,
  "products": [
    {
      "id": 11,
      "name": "Citadel Base: Macragge Blue",
      "faction": "Общие товары",
      "category": "Краски",
      "description": "Синяя базовая акриловая краска для миниатюр.",
      "price": "450.00",
      "stock": 20,
      "tags": "краска синий покраска",
      "beginner_friendly": true
    }
  ]
}
```

Ответ:

```json
{"items":[{"product_id":11,"quantity":1,"reason":"Синий базовый цвет подходит для ваших миниатюр."}],"model":"@cf/meta/llama-3.3-70b-instruct-fp8-fast"}
```

preferences: 5–1200 символов; budget: 1–1 000 000; max_items: integer 1–5, по умолчанию 3; products: массив до 50 записей с уникальными положительными id. Обязательные поля товара: id, name (до 200 символов), price > 0, stock (целое >= 0). description необязательно, до 600 символов. Ограничение тела запроса — 160 000 байт. Внешний вызов модели выполняется только после авторизации и проверки данных.

Worker передаёт модели системный промпт и данные кандидатов, запрашивая JSON Schema. Данные каталога и пожелания отделены от инструкций. Ответ дополнительно проверяется кодом, поскольку схема сама по себе не гарантирует корректность модели.

Ошибки Worker: 400 (JSON/поля), 401 (ключ), 404 (маршрут), 405 (метод), 413 (размер), 415 (Content-Type), 502 (модель/структура ответа), 503 (не настроен ключ). Формат — `{"detail":"…"}`. Сервис не хранит корзины, учётные записи и БД магазина.

Полная спецификация — `cloud_openapi.yaml`.
